## رفع ملف ZIP

إذا كان لديك ملف ZIP جاهز وتريد رفعه هنا في المستودع:

1. افتح صفحة المستودع على GitHub.
2. ادخل إلى تبويب **Code**.
3. اضغط **Add file** ثم **Upload files**.
4. اسحب ملف الـ ZIP أو اختره من جهازك.
5. أضف رسالة commit ثم اضغط **Commit changes**.

> ملاحظة: إذا كان الملف كبيرًا جدًا، قد تحتاج لاستخدام Git LFS أو تقسيمه.
